# Software architecture

How software systems are put together, and how architecture connects to compilers and domain-specific languages (DSLs). This series is still being planned.

## Planned modules

1. **Architectural styles** such as layers, pipes and filters, event-driven systems and microservices
2. **The compiler as an architecture**, a pipeline that goes from lexer to parser to AST to analysis to code generation, where each stage has one job
3. **DSLs**, small languages built for one domain like SQL, regular expressions, build files or configuration, and the difference between internal and external DSLs
4. **Building a DSL** from grammar to parser to AST to interpreter, using a language workbench such as Rascal
5. **Models and code generation**, describing a system in a DSL and generating its code from that description
