# Languages and machines

Formal languages and the machines that recognize them. This series is still being planned.

## Planned modules

1. **Finite automata**, DFAs and NFAs, and how to turn one into the other
2. **Regular expressions**, Kleene's theorem and the pumping lemma
3. **Context-free grammars**, derivations, parse trees and ambiguity
4. **Pushdown automata and parsing**, LL and LR parsers and how they build an AST
5. **Turing machines**, what a computer can and can't do, decidability and the halting problem
