# Languages and machines

Formal languages and the machines that recognize them.

**Status:** planned.

## Planned modules

1. **Finite automata:** DFAs, NFAs, and turning one into the other
2. **Regular expressions:** Kleene's theorem and the pumping lemma
3. **Context-free grammars:** derivations, parse trees, ambiguity
4. **Pushdown automata and parsing:** LL and LR parsers, building an AST
5. **Turing machines:** what a computer can do, and what it can't (decidability, the halting problem)
